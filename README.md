 Grade Calculator - TDD Project

  Project Description
A Java-based grade calculator implemented using  Test-Driven Development (TDD)  methodology. This project demonstrates the Red-Green-Refactor cycle in practice.

 Features
 Grade Conversion Convert percentage scores to letter grades (A, B, C, D, F)
 Pass/Fail Check  Determine if a grade is passing (≥60%)
 Average Calculation  Compute average of multiple grades
 Input Validation  Comprehensive validation for invalid inputs
 Exception Handling  Proper error handling for edge cases
